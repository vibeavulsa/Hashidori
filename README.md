# 橋鳥 Hashidori — Portifólio de Tatuagens

Portifólio digital de **Jean Carlos**, tatuador especializado em arte japonesa tradicional e vintage.

**Marca:** 橋鳥 Hashidori — *"o pássaro da ponte"*

## ✨ Funcionalidades

- **UI Apple Liquid Glass** via [`liquid-glass-react`](https://github.com/rdev/liquid-glass-react) — navbar flutuante, botões e cards com efeito glassmorphism iOS
- **Estética japonesa vintage** — paleta vermilion + ouro + azul profundo, padrão seigaiha, kanji decorativos, tipografia Noto Serif JP & Cormorant Garamond
- **5 seções:** Hero · Sobre · Portifólio · Contato · Footer
- **Ilustrações SVG** — guindaste origami, carpa koi, flores de cerejeira, dragão e padrões geométricos japoneses
- **Design responsivo** — menu hamburger no mobile

## 🚀 Desenvolvimento

```bash
# Instalar dependências
npm install

# Servidor de desenvolvimento
npm run dev

# Build de produção
npm run build

# Preview do build
npm run preview
```

## 🛠 Tecnologias

- [React 19](https://react.dev/)
- [Vite 7](https://vitejs.dev/)
- [liquid-glass-react](https://github.com/rdev/liquid-glass-react)
- CSS puro com variáveis customizadas
- Google Fonts — Noto Serif JP, Cormorant Garamond, Shippori Mincho
